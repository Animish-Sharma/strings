# Report language

The last place a bounded result becomes an unbounded one is the prose, and
nothing in the analysis has to change for it to happen.

## The preferred sentence

> Supported under dataset D, context Z, perturbation P, analysis A, and the
> pre-registered metric set Q. Not established outside those bounds.

It is boring on purpose. It is also the only sentence the evidence supports, and
writing it takes the same time as writing a better-sounding one.

## The escalation ladder

Each step requires evidence the readout does not supply. The scope-language gate
checks the vocabulary against the tiers the bundle declares, so using the words
without the evidence fails rather than persuades.

| From | To | Requires |
|---|---|---|
| association | mechanism | an intervention on the intermediate, not a correlation with it |
| association | causality | the perturbation being the only thing that differed, argued explicitly |
| cellular | organismal | an organism |
| organismal | clinical | a trial |
| one context | generality | a second context |

It is not a word blocklist. Any of these words may be used by declaring the
evidence tier that licenses it. The check is that the vocabulary and the evidence
agree.

## Three specific escalations to watch

- **A transcriptomic signature becoming a mechanism.** The readout is expression.
  Expression changing downstream of a perturbation is consistent with many
  mechanisms and establishes none of them.
- **A within-screen effect becoming a population effect.** The denominator gate
  catches this in the analysis; the prose can still do it afterwards, in one
  sentence, with no number changed.
- **An effect size becoming a therapeutic rationale.** Between the two lie
  target validation, an organism, safety, and a trial.

## Report the bounds, always

Every result here is bounded by dataset, context, perturbation, analysis, and
metric set. A report that does not say so will be read as unbounded — readers
default to generality, and silence is not a hedge.

## Report the negative results too

A failure record that removes a path from consideration is real progress and
belongs in the report at the same weight as a positive. So does an honest stop:
`OPEN`, `PARTIAL`, `STOPPED`, and `REJECTED` are legitimate outcomes, and a
campaign that cannot produce them is not an audit.

## Never say VERIFIED

Not at any tier, not under any design. Empirical support is support for a frozen
dataset, context, and analysis; the word `VERIFIED` in this frame means an
adapter that cannot be argued with covered every obligation. Using it here would
put a perturbation screen and a machine-checked identity in the same box, and the
whole vocabulary exists to keep them apart. The strongest thing this pack can
say is `CHECKED_REPRODUCED`, and it should be said rarely.
