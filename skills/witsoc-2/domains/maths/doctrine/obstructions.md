# Obstruction catalogue — mathematics

The frame's general taxonomy, instantiated. Record each as: what it threatens ·
the evidence · the blocking claim it implies · direct attacks attempted · the
test · the bypass mutation · status.

An obstruction is useful only if it yields a **test**, an **obstruction result**,
or a **bypass mutation**.

| Obstruction | Shape here | Test |
|---|---|---|
| **Extremal** | near-violating configurations crowd the bound | construct the extremal family; is the bound tight? |
| **Parity / modular** | an invariant separates the cases | compute the invariant on small instances |
| **Threshold** | behaviour changes at a critical parameter | locate the threshold numerically first |
| **Compactness** | finite behaviour does not transfer to the infinite case, or the reverse | check whether a compactness argument actually applies |
| **Regularity** | the tool needs smoothness or bounded complexity the object lacks | state the regularity the tool assumes; does the object have it? |
| **Independence / pseudorandomness** | the structure the argument needs is not there | test on a random instance |
| **Precondition** | a known result is one unmet hypothesis away | precondition-audit the citation; is the gap the whole problem? |
| **Formalization** | the sketch hides side conditions that surface only when encoded | probe-formalize the step |
| **Reduction** | the transformation loses equivalence | check both directions of the reduction |
| **Density / counting** | the counting argument is off by the wrong order | recount on small cases |

## Field-specific families

Consult the sub-field's own literature for the standard obstructions before
attacking — most areas have two or three that rule out whole approach classes,
and rediscovering one by exhaustion is expensive.

## Promotion

Three recorded failures sharing one blocker promote that blocker to a named
obstruction. That promotion is the signal the campaign found something real
rather than merely being unlucky.

Three mutation loops on one obstruction with no new evidence: convert it to an
obstruction result or change product.
