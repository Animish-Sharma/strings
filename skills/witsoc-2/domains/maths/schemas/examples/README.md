# Example packets — maths

A complete chain from a real campaign: `campaign.py run --domain maths --tier
kernel` against a Mathlib theorem, admitted VERIFIED with an independent review.

They live here rather than in the frame's `schemas/examples/` because they carry
this field's vocabulary, and a frame directory that carries it stops being a
frame directory. The frame keeps fixture-pack packets, which are domain-neutral
by construction.

Do not hand-edit. A packet edited to satisfy a schema is the curated example
these directories exist to avoid.
