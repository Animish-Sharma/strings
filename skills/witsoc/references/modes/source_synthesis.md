# Source synthesis

Use this mode for status, prior-work, and known-result questions. It is a light
Witsoc path, not an exit from Witsoc.

1. Freeze the exact question, scope, date, and terminology.
2. Resolve the domain pack and load its retrieval capability only.
3. Prefer primary records; bind every material statement to a locator and the
   retrieved bytes or an immutable identifier.
4. Separate established, conditional, bounded, disputed, retracted, and open
   statements. A source's confidence wording does not move frame status.
5. Record contradictory sources and unresolved preconditions.
6. Report what is known, what is inferred, what remains open, and what this
   synthesis must not be used to claim.

Do not start production or a discovery campaign unless the request explicitly
asks for a new claim or the source audit exposes one exact unresolved target.
