# Open discovery

Represent the work as a frozen target and a retained frontier. Activity is not
progress; reward only an admitted product, strict reduction, falsification, new
obstruction, or a discriminating external result.

## Invocation contract

Activation is transactional. Before creating `plan.json`, reports, task
directories, or role workers, run `orchestrator-preflight` and require
its sealed `PREFLIGHT_READY` receipt; `start --preflight` must consume those
exact bytes. Use only the returned Plane locators, including
`witsoc/explorer/SKILL.md` and `witsoc/researcher/SKILL.md`; bare role paths and
invented alias skill names are invalid. A failed activation ends as
`ACTIVATION_FAILED` with no initialized-looking research artifacts.
Use `--statement-file` for long or shell-sensitive requests.

An explicit Witsoc or Explorer-to-Researcher request is executed by the current
invocation. It must not be replaced with a newly triggered root orchestrator or
deep run unless the user explicitly asks for that delegation. A root
orchestrator may launch child role workers in its own session tree, but it
remains the Witsoc coordinator and resumes when they return. User-bound
workspace and task paths are immutable. Otherwise a worker may use an isolated
worktree only when its base revision and returned artifact paths are declared;
the coordinator must harvest and import those bytes before arbitration. A spawn
receipt records lifecycle only, not Explorer triage or a completed loop.

The stage gate is strict:

1. Explorer reads the bound prior work and emits a sealed episode/round,
   expands the frontier, or records a resumable `PAUSE_WITH_FRONTIER`.
   `HONEST_STOP` is a separately reviewed, post-search terminal exception.
2. Researcher runs only when that packet exists, stays within its target,
   workspace, and episode return condition, and returns one sealed delta. It
   has no campaign-stop authority.
3. The coordinator joins the return and re-enters Explorer for validation,
   merge, and fresh arbitration. It then audits and finalizes before completion.

In a mail-driven deep run, ending a turn while a child is pending is a yield,
not a terminal result. Resume the same root run on worker mail.

## Discovery cycle

1. Import prior evidence and failed semantic routes before proposing work.
2. Build a small portfolio spanning at least three epistemic lanes, three
   distinct semantic routes, and two semantic cores: retrieve, refute, reduce,
   construct, transfer, measure, or verify. A narrower portfolio needs a
   recorded exception tied to the frontier.
3. Rank by target leverage, expected information gain, checkability,
   reversibility, novelty, transfer value, cost, and recoupling risk.
4. Compile a domain problem packet and dependency-closed operator plan. Load
   only doctrine named by its selected operators.
5. Explorer issues one sealed episode for coupled work. It may issue a round of
   two to eight attacks only when actors, semantic routes, failure domains, and
   resource keys are independent against one immutable snapshot.
6. Each Researcher receives a sealed capsule and returns one sealed delta. It
   cannot inspect sibling work or choose its successor.
7. Explorer performs a deterministic, conflict-visible merge, compares the
   changed frontier, and then chooses continue, expand/reframe, pause, wait,
   demote, or a fully gated terminal action.

A no-progress return names the surviving obstruction, strongest valid partial
result, revival condition, and next mechanism-distinct proposal.
Re-entry requires a changed semantic axis plus evidence, not a renamed method.
Operator plans and round agreement rank work; neither can admit status.
