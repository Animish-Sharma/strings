# Artifact production

Use this mode for one already selected route and one frozen target. Load the
Generator contract and only the domain capabilities needed to create and check
that artifact.

Build the obligation graph before writing. Produce in an isolated workspace,
bind every external dependency, and send current bytes through the domain
adapter. Repairs mutate one diagnosed axis at a time. Stop at the domain's
repeat threshold and return the failure signature rather than spending on a
cosmetic variant.

Production emits candidates, diagnostics, and receipts. It does not admit its
own output or choose a new research route.
