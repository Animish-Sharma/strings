# Claim verification

Use this mode when a precise claim already exists.

Freeze the target, resolve the domain, identify the cheapest backend capable of
falsifying the requested assurance level, and run the domain's declared gates.
The result is a candidate until the frame reducer derives every required check
from sealed evidence. A missing capability or skipped gate is `NOT_RUN`, never
a pass.

Check target binding, current artifact bytes, dependencies, open gaps, fidelity,
refutation pressure, and required independence. Report the strongest admitted
status and the exact ceiling that prevented anything stronger.
